# ИИ-агент проверки требований

Проект для **BCC-HUB x MNU FinTech Hackathon**. Агент выполняет статическое ревью документов с программными требованиями по ISO/IEC/IEEE 29148:2018 и IEEE Std 830-1998 и формирует доказательный Markdown-отчёт на русском языке.

Агент не тестирует готовую программу. Он проверяет качество документа **до разработки**: выделяет атомарные требования, находит двусмысленность, непроверяемость, противоречия, пропуски, несогласованные термины и лишние проектные решения.

## Возможности

- входные форматы: `.md`, `.txt`, `.pdf`, `.docx`;
- чтение таблиц из DOCX;
- предупреждение о PDF-страницах без извлечённого текста;
- обработка больших документов фрагментами;
- автоматическая нумерация `REQ-001`, `REQ-002`, …;
- проверка каждого требования и всего набора;
- контроль точности цитат модели;
- детерминированная структура отчёта;
- автоматический Git commit/tag в паспорте;
- повтор запросов при временных ошибках Gemini;
- отсутствие секретов в исходном коде.

## Как работает агент

1. Читает исходный документ.
2. Делит большой текст на безопасные фрагменты.
3. С помощью Gemini выделяет атомарные требования.
4. Проверяет, что каждая цитата действительно присутствует в документе.
5. Проверяет требования пакетами по критериям качества.
6. Ищет противоречия и пробелы во всём наборе.
7. Кодом собирает отчёт обязательной структуры и сохраняет его в файл.

## Требования

- Python 3.11 или новее;
- интернет для обращения к Gemini API;
- бесплатный API-ключ Google AI Studio.

## Установка

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

### Linux/macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

## Получение бесплатного Gemini API-ключа

1. Откройте [Google AI Studio](https://aistudio.google.com/apikey).
2. Войдите в Google-аккаунт.
3. Нажмите **Create API key**.
4. Откройте локальный файл `.env`.
5. Вставьте ключ после `GEMINI_API_KEY=`:

```env
GEMINI_API_KEY=ваш_ключ
GEMINI_MODEL=gemini-2.5-flash
```

Файл `.env` включён в `.gitignore`. Не отправляйте его в GitHub и не публикуйте ключ.

## Запуск одной командой

Из корня проекта:

```bash
python main.py --input docs/requirements.md --output output/report.md
```

Короткая форма:

```bash
python main.py -i docs/requirements.md -o output/report.md
```

После завершения готовый отчёт будет сохранён в `output/report.md`. Если папки `output` нет, агент создаст её автоматически.

Дополнительные параметры:

```bash
python main.py --help
```

Пример выбора модели:

```bash
python main.py -i docs/requirements.md -o output/report.md --model gemini-2.5-flash
```

## Структура отчёта

1. Паспорт прогона: документ, дата и время, модель, версия агента.
2. Таблица нарезки требований.
3. Проверка каждого требования.
4. Проверка всего набора.
5. Сводка метрик и критичных дефектов.
6. Вердикт Go / Conditional / No-Go и приоритет исправлений.

Каждое замечание содержит подтверждённую цитату, критерий, критичность, риск и рекомендацию.

## Известное ограничение

`pypdf` извлекает текст из обычных PDF, но не распознаёт изображения. Если документ является сканом, выполните OCR перед запуском. Агент выведет предупреждение, если страницы не содержат извлекаемого текста.
